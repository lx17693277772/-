01 工具简介

该工具是一个纯前端网页，不需要安装软件。图片在当前浏览器中读取和标注，可在电脑浏览器中使用，也可部署到普通静态网站。

主要功能

  • 读取照片的宽度、相机、焦距、GPS 高度和拍摄坐标等 EXIF 信息。
  • 根据 GPS 绝对高度、地面高程和水平视场角自动计算像素比例尺。
  • 使用图像中的已知现实距离进行比例尺标定，覆盖自动计算结果。
  • 依次点击两个端点，测量直线距离，并连续添加多段测量。
  • 修改结果名称、端点像素坐标或手工修正长度。
  • 复制文字报告，或导出带测量线和数值的原尺寸 PNG 图片。

适合使用

地面近似平整的俯视或正射照片、沿着同一地平面测量道路宽度、地块长度、目标间距离等。

不适合直接使用

大面积倾斜拍摄、跨越不同高度的目标、镜头畸变明显的照片、面积和体积计算，以及需要测绘级精度的场景。

重要 工具计算的是图像中两个像素端点对应的直线距离。结果精度取决于高度、地面高程、视场角、标定距离和照片几何条件。

02 快速开始

推荐按以下顺序操作。首次使用时可以直接使用已知距离标定，通常比依赖相机参数更容易核对。

1

打开测距页面

在 Edge 或 Chrome 中打开在线地址。公开版本可能没有默认示例图，页面中央出现空白或替代文字属于正常现象。

2

添加图片

点击“添加图片”，或把图片文件拖到左侧图像区域。建议使用未经聊天软件压缩、未裁切且保留 EXIF 的原始照片。

3

检查自动读取的信息

等待片刻，查看文件名下方是否出现相机型号、分辨率、焦距、GPS 高度和坐标。读取成功后，部分参数会自动填入。

4

确认参数或执行标定

如果参数可信，点击“应用参数”。如果画面中有已知尺寸的参照物，选择“标定比例”，用已知现实距离建立比例尺。

5

依次点击两个端点

在“测量”模式下，点击起点，再点击终点。完成后会自动开始下一段测量。

6

检查并导出

对照结果列表检查端点位置和数值，必要时修改或“图上重取”。最后复制文字结果或保存标注图片。

最短操作路径 添加图片 → 标定比例 → 测量 → 保存图片。只测量两点时，不一定需要使用自动比例尺。

04 参数与自动比例尺

自动比例尺适合照片带完整 EXIF 且相机参数可信的情况。所有输入均使用十进制数值，不要输入单位文字。

参数示例填写方法
GPS 绝对高度 (m) 1214.807 无人机拍摄点的海拔高度，通常从照片 EXIF 自动读取。
地面高程 (m) 1113.0 拍摄位置下方的地面海拔。可手工填写，也可通过坐标读取 DEM。
水平视场角 (°) 104.3 相机水平视场角。若有 35mm 等效焦距，工具会尝试换算。
图像宽度 (px) 4000 原始照片的像素宽度，会在加载图片时更新。
坐标 (lat, lon) 38.272833, 110.343181 纬度在前、经度在后，使用十进制度。只用于读取地表高程。

自动计算关系

相对地面高度 = GPS 绝对高度 - 地面高程
像素比例尺 = 2 × 相对高度 × tan(水平视场角 ÷ 2) ÷ 图像宽度
实际距离 = 两个端点的像素距离 × 像素比例尺
“应用参数”按钮 点击后会清除已有的已知距离标定，重新使用当前相机参数计算比例尺，并更新全部测量结果。

读取地表高程

  1. 确认“坐标”格式正确，例如 38.272833, 110.343181。
  2. 点击“读地表高程”。
  3. 按钮暂时禁用，读取成功后地面高程自动更新。
  4. 工具随后清除已知距离标定，并按新的自动比例尺计算结果。
需要联网 地表高程来自 Open-Elevation 在线接口。接口不可用、坐标无效或当前网络无法访问时，读取会失败，可改为手工填写地面高程。

06 已知距离标定

当自动比例尺不可信，或者画面中存在尺寸确定的参照物时，优先使用已知距离标定。标定比例会覆盖相机参数计算出的比例尺。

适用参照物

  • 已经测量过的道路宽度、车位宽度、建筑边长、球场地线或标准标尺。
  • 参照物与待测目标尽量处在同一高度平面，并且距离相机大致相同。
  • 参照物在图中的两个端点应清晰、间距尽量长，以提高比例尺稳定性。

操作步骤

1

选择“标定比例”

提示条会变为“点击两个已知距离的参考点”。

2

点击参照物两端

第一条线和两个黄色端点确认后，会弹出“标定比例尺”窗口。

3

输入已知距离

填写参照物两个端点之间的真实现实距离，单位为米。必须是大于 0 的数字。

4

点击“应用标定”

工具计算“已知距离 ÷ 像素距离”，更新顶部比例尺，并重算所有自动测量结果。

标定比例尺 = 已知现实距离 (m) ÷ 参照物像素距离 (px)

恢复自动比例尺

修改参数后点击“应用参数”，或重新执行“读地表高程”。两种操作都会清除已知距离标定，恢复自动比例尺。单独修改输入框不会立刻覆盖已应用的手工标定。

标定建议 标定距离越长，端点定位误差对比例尺的影响越小。例如使用 20 米道路长度通常比使用 0.5 米标尺更稳定。

07 修改与校正结果

在结果列表中点击铅笔图标，可打开“修改测量结果”窗口。

字段或按钮用途
结果名称 为测量项设置易读名称，最长 40 个字符。留空时恢复为 M1、M2 等默认名称。
起点 X / Y (px) 起点在原始图片像素坐标系中的坐标。原点在左上角，X 向右，Y 向下。
终点 X / Y (px) 终点在原始图片像素坐标系中的坐标，必须在图片范围内。
手工修正长度 (m) 填写正数后，该结果直接使用这个长度，并显示“手动”标记。留空后恢复自动计算。
图上重取 关闭编辑窗口，在图片上重新点击新的起点和终点。重取后会取消该结果的手工修正长度。
删除 删除当前结果。删除后撤销按钮不会恢复，推荐先核对再操作。
保存 校验坐标、距离和手工长度后保存，并立即刷新列表和图片标注。

什么时候使用“图上重取”

  • 第一次点击的端点位置不准。
  • 缩放后发现端点落在目标边缘之外。
  • 目标位置改变，需要保留原结果名称但替换测量位置。

什么时候使用“手工修正长度”

只有在已经通过外部可靠方法得到现实长度，并且希望报告中保留该结果时使用。手工数值会覆盖本工具根据像素和比例尺计算出的结果，不会反向修正比例尺。

09 精度与适用范围

当前算法进行二维图像测量，不执行完整的摄影测量相机模型和倾斜校正。因此，结果应被视为估算值。

影响精度的主要因素

因素影响
相对高度高度误差会按比例传递到长度结果。高度越小，同样比例误差造成的结果误差越小。
地面高程地面高程不准确会直接改变相对高度，尤其对自动比例尺影响明显。
视场角视场角或等效焦距不准确，会改变整个画面的比例尺。
照片裁切与压缩裁切会破坏原始视场角关系，聊天软件压缩还可能移除 EXIF。
镜头畸变画面边缘的直线拉伸会使像素距离产生系统误差。
拍摄倾角倾斜越大，图像平面距离与真实地面距离的差异越大。
地面高差单个地面高程无法表示起伏地形，跨越坡面或不同高度目标时误差增大。
端点定位端点点错或点偏会直接改变像素距离，应放大后精确选取。

提高结果可靠性的方法

  1. 优先使用同一地平面上的已知距离完成标定。
  2. 标定线尽量长，并使用清晰、确定的端点。
  3. 目标与参照物尽量位于画面同一区域和相同高度。
  4. 使用原始照片，不要使用经过裁切、旋转或聊天软件压缩的副本。
  5. 放大图片后再点击端点，完成后复查每条线是否贴合目标边缘。
  6. 使用多个独立参照物重复标定，比较比例尺是否接近。
专业用途提示 不应将本工具的单一结果直接用于工程结算、法律取证、测绘备案或安全决策。专业用途需要经过控制点检核、畸变校正和精度评估。

10 隐私与数据保存

图片如何处理

通过“添加图片”载入的图片使用浏览器本地对象 URL 读取。测距工具本身不会主动把图片内容上传到服务器，测量也在当前浏览器中完成。

哪些网络请求可能发生

功能网络数据
页面界面资源从 unpkg 和 jsDelivr 加载图标及 EXIF 解析库，外部服务可获取访问 IP 和请求信息。
读取地表高程填写的拍摄坐标会发送到 Open-Elevation 接口，用于查询对应位置的地面高程。
GitHub Pages访问页面时由 GitHub Pages 提供 HTML 文件，并按 GitHub 的访问日志策略处理请求。
敏感照片 如果照片包含精确位置、人员、设施或其他敏感信息，请确认当前网络的隐私要求。最稳妥的方式是将页面和所需脚本部署到受控网络，并关闭外部高程查询。

结果是否保存

工具没有账号、数据库或项目保存功能。图片、参数、端点和结果只保留在当前页面内存中。发生以下操作时，结果会丢失：

  • 刷新或关闭页面。
  • 添加另一张图片。
  • 点击“清空”。
  • 浏览器崩溃、标签页被系统回收或设备断电。

打开后没有默认照片 公开仓库没有上传示例照片，这是隐私保护设置。 点击“添加图片”或把自己的照片拖入工作区。

12 快速检查表

测量前

  • 照片是否为未压缩、未裁切的原图？
  • GPS 高度、地面高程、视场角和图像宽度是否正确？
  • 是否可以用更可靠的已知距离进行标定？
  • 待测目标与参照物是否处于相近的高度平面？

测量中

  • 是否已放大图片并准确点击端点？
  • 测量线是否完整覆盖目标，没有越过端缘？
  • 每条结果是否已命名，便于后续识别？
  • 比例尺或地面高程变化后，结果是否已重新计算？

测量后

  • 是否用第二个参照物或常识进行了复核？
  • 是否需要手工修正长度，并确认修正依据？
  • 是否已点击“复制结果”保存文字报告？
  • 是否已点击“保存图片”保存带标注的 PNG？
推荐归档内容 原始照片、用于标定的参照物及已知尺寸、复制出的文字报告、保存的标注图片。这样便于以后复现和检查测量结果。
